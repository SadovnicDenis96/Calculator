Да, вы можете изменить интерфейс калькулятора через Qt Designer, добавив кнопки для косинусов и других функций. Однако, если вы измените интерфейс (например, добавите новые кнопки), вам потребуется также обновить соответствующий код Python, чтобы он работал с новыми элементами интерфейса.

Вот основные шаги, которые нужно выполнить:

Измените интерфейс:

Откройте файл .ui в Qt Designer.
Добавьте нужные кнопки и настройте их свойства (например, текст, имя объекта и т.д.).
Сохраните изменения:

После внесения изменений в интерфейс сохраните файл.
Перегенерируйте код:

Используйте pyside6-uic или аналогичный инструмент, чтобы сгенерировать новый Python-код из вашего изменённого .ui файла.
Обновите код:

Убедитесь, что ваш Python-код правильно обрабатывает новые кнопки. Вам может понадобиться добавить обработчики событий для новых кнопок (например, функции для вычисления косинуса и т.д.).
Тестирование:

Запустите приложение и проверьте, что всё работает корректно.
Если вы будете следовать этим шагам, ваш код будет работать, даже если интерфейс изменится. Главное — не забывать обновлять обработчики событий и логику калькулятора в соответствии с новыми элементами интерфейса.
